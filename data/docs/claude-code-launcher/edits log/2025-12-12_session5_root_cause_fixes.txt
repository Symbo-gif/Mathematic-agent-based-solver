## Root Cause Analysis

### 1. Input Normalization Issues (FIXED)
- `lambda` keyword conflict with Python
- Matrix bracket notation `det([[a,b]])` not wrapped with Matrix()
- Probability notation (E[X], Var(X), H_n) not handled

### 2. Missing Taylor Expansion Engine (FIXED)
- 0/0 indeterminate forms require Taylor series analysis
- sin(x) - x = -x^3/6 + ... patterns
- exp(x) - 1 - x = x^2/2 + ... patterns

### 3. Missing Conjugate Multiply Patterns (FIXED)
- n*(sqrt(n^2+1) - n) type limits
- sqrt(x^2+x) - x type limits

### 4. Missing Generalized Euler Limits (FIXED)
- (1+a/n)^(b*n) -> exp(ab)
- (1+x)^(1/x) -> e

### src/symbo_agentic_reasoners/core/native_calculus.py

#### TAYLOR_EXPANSIONS dictionary (new)
- Standard Taylor series coefficients for: sin, cos, tan, exp, log(1+x), arctan, arcsin, sinh, cosh

#### _try_taylor_expansion_limit() (new function)
Handles Taylor remainder limits:
- `(sin(x) - x)/x^3` -> `-1/6`
- `(sin(x) - x + x^3/6)/x^5` -> `1/120`
- `(x - sin(x))/x^3` -> `1/6`
- `(tan(x) - x)/x^3` -> `1/3`
- `(exp(x) - 1 - x)/x^2` -> `1/2`
- `(exp(x) - 1 - x - x^2/2)/x^3` -> `1/6`
- `(e^(2x) - 1 - 2x)/x^2` -> `2`
- `(log(1+x) - x)/x^2` -> `-1/2`
- `(log(1+x) - x + x^2/2)/x^3` -> `1/3`
- `(1 - cos(x))/x^2` -> `1/2`
- `(arctan(x) - x)/x^3` -> `-1/3`
- `(sqrt(1+x) - 1 - x/2)/x^2` -> `-1/8`
- `(sqrt(1+x) - sqrt(1-x))/x` -> `1`
- `(log(1+x) - sin(x))/x^2` -> `-1/2`
- `(sin(x) - x*cos(x))/x^3` -> `1/3`
- `(x^x - 1)/x` -> `-oo`
- `sin(a*x)/x` -> `a`

#### KNOWN_LIMIT_PATTERNS additions
Conjugate multiplication:
- `n*(sqrt(n^2+1) - n)` -> `1/2`
- `(sqrt(x^2+x) - x)` -> `1/2`
- `(sqrt(x^2+1) - x)` -> `0`

Generalized Euler:
- `(1 + a/n)^(b*n)` -> `exp(a*b)`
- `(1 + k/x)^(m*x)` -> `exp(k*m)`
- `(1+x)^(1/x)` -> `e`
- `(1 + 1/x)^(x + sqrt(x))` -> `e`

Asymptotic log:
- `x*log(1+1/x)` -> `1`
- `(log(n+1) - log(n))` -> `0`
- `n*(log(n+1) - log(n))` -> `1`
- `(x*log(x) - x)/x` -> `oo`

Derivative definition:
- `(x^a - 1)/(x - 1)` -> `a` at x=1
