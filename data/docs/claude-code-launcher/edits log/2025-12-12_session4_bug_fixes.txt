### 3. src/symbo_agentic_reasoners/core/native_calculus.py

#### Log-Power Singularity Fix (lines 8636-8682)
- Rewrote `_check_log_power_integral()` with comprehensive pattern matching
- New patterns handle all forms:
  - `(log(x))^m / x^p` - with outer parens and explicit power
  - `(log(x))^m / x` - with outer parens, p=1 implicit
  - `log(x)^m / x^p` - without outer parens
  - `log(x)^m / x` - p=1 implicit
  - `log(x) / x^p` - m=1 implicit
  - `log(x) / x` - both powers implicit (m=1, p=1)
  - `x^(-p) * log(x)^m` - reversed order
- Now correctly returns "divergent" for p >= 1 cases like `(log(x))^2/x`

#### Endpoint Singularity Detection (lines 8006-8068)
- Rewrote `_evaluate_limit()` to properly handle finite endpoint limits
- New behavior for finite limits:
  1. First try direct evaluation
  2. If that fails (singularity), approach from inside the interval
  3. Use epsilon values [0.1, 0.01, 0.001, 0.0001, 0.00001]
  4. Detect divergence if values grow unboundedly
  5. Return +/-inf for detected divergence
- Added `from_inside` parameter: '+' (from right), '-' (from left)

#### Updated _evaluate_limit calls (lines 3723-3741)
- Upper bound: approach from left (within interval: '-')
- Lower bound: approach from right (within interval: '+')
- This correctly detects endpoint singularities like atanh(x) at x=+/-1
