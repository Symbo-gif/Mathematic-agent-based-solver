## Technical Notes

### Symbol Assumption Fix
The key insight was that SymPy's sympify() creates symbols without mathematical assumptions.
For limit computation of expressions like (1/2)**n to work correctly, the symbol n must have:
- positive=True
- integer=True

Without these, sp.limit((1/2)**n, n, oo) returns the expression unchanged instead of 0.

Solution: Replace the symbol in the parsed expression with a properly-assumed symbol:
```python
n = sp.Symbol(var, positive=True, integer=True)
expr = sp.sympify(expr_str)
for s in expr.free_symbols:
    if s.name == var:
        expr = expr.subs(s, n)
        break
```

### Parity Clarification
The analysis file claimed x**3*sin(x) is odd, but mathematical verification shows:
- odd * odd = even (since (-1)^3 * (-1) = 1)
- x^3 is odd, sin(x) is odd
- Product is EVEN: f(-x) = (-x)^3 * sin(-x) = -x^3 * -sin(x) = x^3 * sin(x) = f(x)

So the numeric integral result of 0.354 over [-1,1] is mathematically correct.
