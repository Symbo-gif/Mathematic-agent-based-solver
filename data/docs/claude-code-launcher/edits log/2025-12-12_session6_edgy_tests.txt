## Root Causes Identified & Fixed

### 1. Special Function Normalization (CRITICAL)
**Problem:** BesselJ, AiryAi, etc. were mangled by implicit multiplication
- `BesselJ(1,x)` -> `BesselJ*(1,x)` (broken!)

**Fix:** Added to PROTECTED_FUNCTIONS in input_normalizer.py:
- BesselJ, BesselY, BesselI, BesselK (and lowercase variants)
- AiryAi, AiryBi, Ai, Bi
- hankel1, hankel2, jn, yn, spherical_jn, spherical_yn
- polylog, lerchphi, dirichlet_eta, Lambda, mu, phi, totient
- hermite, laguerre, legendre, chebyshev, jacobi
- H_n, M_X, P, E, Var, Cov, Phi

### 2. Uppercase Variables Treated as Functions (CRITICAL)
**Problem:** `N` in SymPy is `sp.N` (numerical eval function)
- `diophantine(x**2 - D*y**2 - N)` -> "unsupported operand type(s) for -"

**Fix:** Modified safe_parser.py:
- Added uppercase A-W to COMMON_VARIABLES
- Changed _create_safe_locals() to let symbols OVERRIDE functions:
  ```python
  for var in COMMON_VARIABLES:
      safe_locals[var] = sp.Symbol(var)  # No "if var not in safe_locals" check
  ```

### 3. Missing Asymptotic Rule Engine (MAJOR)
**Problem:** Limits involving special function asymptotics not evaluated

**Fix:** Added 4 new rule functions in native_calculus.py:
- `_try_special_function_asymptotic()` - Gamma ratios, zeta poles, log-Gamma
- `_try_nested_log_limit()` - log(log(x))/log(x) -> 0
- `_try_stirling_limit()` - n!/n^n using Stirling
- `_try_asymptotic_difference_limit()` - f(x) - asymptotic_expansion

### 4. Diophantine Bounded Search Missing
**Problem:** SymPy throws NotImplementedError for many equations

**Fix:** Added `_bounded_diophantine_search()` in solver_engine.py:
- Grid search for 2-3 variable equations
- Range: [-100, 100] for each variable
- Correctly solves x^2 - y^3 - 1 = 0: {(-1,0), (1,0), (-3,2), (3,2), (0,-1)}

### 5. Parametric Diophantine Detection
**Problem:** Equations with symbolic D, N parameters caused timeouts

**Fix:**
- Detect parameters vs target variables
- Return symbolic result for parametric equations:
  ```
  "Parametric Diophantine equation in (x, y) with parameters (D, N)..."
  ```

## Mathematical Rules Implemented

### 1. Stirling's Approximation Rule
- n! ~ sqrt(2*pi*n) * (n/e)^n
- Used for factorial/Gamma ratio limits

### 2. Zeta Pole Expansion Rule
- zeta(1+epsilon) = 1/epsilon + gamma + O(epsilon)
- Used for zeta(1+1/x) - x limits

### 3. Bessel Asymptotic Rules
- Small arg: J_n(x) ~ (x/2)^n / Gamma(n+1)
- Large arg: J_n(x) ~ sqrt(2/(pi*x)) * cos(x - n*pi/2 - pi/4)

### 4. Airy Asymptotic Rules
- Ai(x) ~ exp(-2x^(3/2)/3) / (2*sqrt(pi)*x^(1/4)) as x->+oo
- Bi(x) ~ exp(+2x^(3/2)/3) / (sqrt(pi)*x^(1/4)) as x->+oo

### 5. MGF/CGF Expansion Rule
- M_X(t) = 1 + mu*t + sigma^2*t^2/2 + kappa_3*t^3/6 + ...
- CGF(t) = log(M_X(t)) = mu*t + sigma^2*t^2/2 + kappa_3*t^3/6 + ...

### 6. Log Growth Hierarchy Rule
- log(log(x)) << log(x) << x^epsilon for any epsilon > 0
- Used for nested log limits

### 7. Bounded Integer Search Rule
- When algebraic methods fail for diophantine equations
- Search [-N, N] grid for small N (default 100)

### 8. Parameter vs Variable Detection Rule
- Target variables: x, y, z, w, u, v, m, n, k, p, q (lowercase common)
- Parameters: D, N, A, B, etc. (uppercase or uncommon)
- Parametric equations get symbolic solution format
