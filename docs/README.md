# Documentation Hub

This directory is the single home for project documentation and historical reports.
Milestone summaries that previously lived in the repository root have been centralized
under `docs/reports/` to keep the top level clean and make it easier to find artifacts.

## Directory map
- `reports/` – status, milestone, stress-test, coverage, and optimization reports (see
  `docs/reports/README.md` for category details).
- `benchmarks/` – ODE benchmark outputs and performance scorecards.
- `context/` – research references, consolidation notes, and system context used during
  development.
- `working_notes/` – prompt and rule snippets captured during earlier sessions.
- `archive/` and `archive_2025/` – older plans, decomposition guides, and security notes.
- Domain- or comparison-specific briefs (e.g., `COMPETITIVE_EXECUTIVE_SUMMARY.md`,
  `COMPARATIVE_ANALYSIS_*.md`) remain at this level for quick access.

## Adding new documents
- Place new status or milestone reports in the appropriate `docs/reports/` subfolder.
- Keep benchmark data in `docs/benchmarks/` and research/context materials in
  `docs/context/`.
- Use the existing archives for historical material that is no longer active.
