SECTION 1: AGENT HIERARCHY OVERVIEW
================================================================================

TIER 1: ORCHESTRATOR (1 agent)
    Main coordinator that decomposes problems, routes to supervisors, and 
    synthesizes final results. NEVER computes directly - only delegates.

TIER 2: SUPERVISORS (38 agents)
    Domain-specific coordinators that route tasks to appropriate specialists.
    Acts as "foremen" for their domain - they coordinate but never compute.

TIER 3: SPECIALISTS (220+ agents)
    Task executors that perform actual mathematical computations using native
    Python implementations. Organized across 30+ specialized domains.

BASE AGENTS (2 agents)
    Problem analysis and notation translation support agents.

SYNTHESIS AGENTS (4 agents)
    Result synthesis, proof construction, and formal translation agents.

PROVERS (2 agents)
    Formal verification and proof validation agents.

COORDINATORS (1 agent)
    Multi-domain team coordination agent.

SECTION 11: BDI COGNITIVE ARCHITECTURE
================================================================================

All agents inherit from the BDI (Belief-Desire-Intention) framework:

BELIEFS (B)
   - Agent's knowledge about the world
   - Internal model of reality
   - Examples: "problem_type", "variable_value", "theorem_applicable"

DESIRES (D)
   - Agent's ultimate high-level goals
   - Objectives the agent wishes to achieve
   - Examples: "solve_integral", "factor_polynomial", "verify_proof"

INTENTIONS (I)
   - Agent's committed plan of action
   - Specific course chosen after deliberation
   - Examples: "apply_risch_algorithm", "use_substitution"

BDI CONTROL LOOP:
   1. PERCEIVE: Update beliefs from environment (Blackboard, messages)
   2. DELIBERATE: Compare beliefs against desires to generate new intentions
   3. MEANS-END: Select concrete plans to achieve intentions
   4. EXECUTE: Execute one step of current intention
   5. Repeat

CRITICAL PRINCIPLE:
   Cognitive agents NEVER compute directly. They:
   - Reason about problems (deliberation)
   - Generate plans (means-end reasoning)
   - Delegate computation to native engines or specialists (execution)
   - Verify and interpret results (belief update)
