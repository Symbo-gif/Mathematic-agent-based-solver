# Reports Index

Centralized hub for milestone documents previously scattered across the repository root.
Use these categories when adding new reports to keep navigation predictable.

## Categories
- `phase_progress/` – phase completion reports, validation summaries, and implementation plans.
- `stress_tests/` – stress, learning-system, and supervisor-focused stress-test results.
- `sessions/` – session-level accomplishment and final status reports.
- `optimization/` – optimization and ODE accuracy improvement notes.
- `coverage/` – coverage improvement reports plus baseline/current/final coverage snapshots.
- `analysis/` – system-wide audits and external analysis notes.

Each file retains its original name for traceability. Choose the closest category for new
reports and keep coverage.json at the repository root to align with tooling defaults.
