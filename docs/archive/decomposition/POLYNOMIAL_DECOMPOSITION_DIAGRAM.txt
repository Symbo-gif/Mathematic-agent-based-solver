ALGORITHM HIERARCHY:
-------------------

try_domain_solve()
├── [Degree 1] → solve_linear
├── [Degree 2] → solve_quadratic
├── [Degree 3] → solve_cubic
│                (or rational roots first)
├── [Degree 4] → solve_quartic
│                (or biquadratic)
│                (or rational roots first)
└── [Degree 5+] → find_rational_roots
                  → newton_raphson
                  → SymPy fallback

├── factor_difference_of_squares
├── factor_difference_of_cubes
├── factor_sum_of_cubes
├── factor_gcd
└── SymPy fallback
